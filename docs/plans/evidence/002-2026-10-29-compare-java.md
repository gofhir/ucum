### java-decimal-precision — deliberate, 435 cases

Java's Decimal rounds each result to the precision it attributes to the literals of the definitions and of the input, so it prints fewer digits than the value has (1 [qt_us] is 0.000946 m3, exactly 0.000946352946). The definitions are exact; this package computes them exactly.

Ucum-java: definitions/XmlDefinitionsParser.java:125-130 (a value with a decimal point gets 24 digits, an integer such as the 231 of [gal_us] only the digits it has), Decimal.java:601-620 (multiply keeps the lower precision) and :722-760 (divide rounds to it); the precision Java declares for each value is in the result file.
